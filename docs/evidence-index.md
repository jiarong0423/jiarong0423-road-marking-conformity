# 證據索引:引用任何一個數字之前先看這張表

2026-09-22,記錄者建立。**用途:這是引用的前置關卡。**
要引用哪一個數字、哪一句話、哪一張圖,先在這裡找到它的編號,
看「今天能不能重跑」和「誰驗過」兩欄,再決定敢不敢寫進交付物。

編號 `EV-NN` 一經指派就不再改變。**撤回的編號留在表上標 `撤回`,不重用。**

「誰驗過」只有三種值:

| 值 | 意思 |
|---|---|
| **記錄者** | 記錄者本人當次跑過那條指令、或當次打開那張圖看過。指令與座標寫在同一列或註腳 |
| **未復驗** | 只有清冊講過,記錄者沒有自己跑/自己看。**等同於沒有驗** |
| **撤回** | 查過,而且不成立 |

一條硬規則,這張表自己也受它管:**「記錄者」這三個字不得出現在
記錄者沒有親自執行過的那一列。**
