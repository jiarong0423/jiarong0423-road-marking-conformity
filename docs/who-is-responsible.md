# 這是誰的工程，2026-09-20

使用者要我查討論區。查到的不是討論區，是主管機關——而那比討論區有用。

## 不是道路工程，是捷運工程

| | |
|---|---|
| 工程 | **捷運土城樹林線**（萬大—中和—樹林線 第二期）CQ890 區段標 |
| 主管機關 | **新北市政府捷運工程局**（DORTS 新北） |
| 承包商 | **遠揚營造工程股份有限公司** |
| 聯絡 | (02) 2676-2468、0918319800、2767-2468#200 |

**這解釋了為什麼道路挖掘許可裡查不到。** 捷運工程不走管挖許可，
先前那份查詢的結論（「沒有白天長期佔用的挖掘許可」）因此不是矛盾，
是查錯登記簿。我當時寫的但書是對的。

## 官方公告的配置

> 樹林區中正路忠義街至萬壽路一段間及中正路248巷至三多路間施作捷運墩柱與基礎，
> 於道路中央架設施工圍籬，**架設後為雙向各兩車道配置**。
>
> 交維措施：調整交通號誌、設立指引牌面、增派義交協助引導、規劃替代道路。

那則公告是 **115年（2026）4月16日起至 2026/05/31**——是後期階段，
不是 2025-06 槽化線那個狀態。工程分多階段，早期階段的公告還沒找到。

## 「雙向各兩車道」與實測一致

| | 路面標字 | 車道數 |
|---|---|---|
| 2022-11 | 兩個 **50** | 2 |
| 2025-06 | 兩個 **30** | 2 |

車道**數**沒被減。被改的是速限（50→30）與車道寬度，以及進入縮減段的
漸變率——那才是量到只夠 28 km/h 的東西。

## 七年，不是三週

通車預計 2031-09。從 2024 年圍籬進場算起，這個狀態要維持約七年。

這對標準的適用有影響。《施工之交通管制守則》那套漸變段公式寫給
**施工期間的臨時配置**，寬鬆的前提是短期。一個只夠 28 km/h 的漸變段
存在三週是一回事，存在七年是另一回事——後者實質上是新的道路幾何，
該用《市區道路及附屬工程設計規範》而不是施工守則來看。

這是論點不是量測，寫在這裡備查。

唯一找到的公開抱怨是一則 Threads 貼文，內容是自製「樹林中正路替代道路方案」

另有自由時報一則報導「捷運土城樹林線施工 拆除分隔島交管」。

## 可以去問誰

主管機關明確了，所以申請資料有對象：

- **新北市政府捷運工程局** — 交通維持計畫、各階段的施工圍籬配置圖
- **遠揚營造** — 現場交維，但他們沒有義務對民眾提供文件
- 交維計畫的審查在**新北市交通局**

要問的具體文件：**2025 年上半該階段的交通維持計畫**，其中的
漸變段設計圖與核准的速限。那份文件會直接回答「畫成這樣是誰核准的」。
