## 「維持多久」的答案

**契約工期 2310 日曆天 = 6.32 年。** 那不是臨時交維的時間尺度。

《施工之交通管制守則》的漸變段公式，其寬鬆性建立在「施工期間的臨時配置」
這個前提上。六年三個月的配置，實質上就是這條路在這段期間的幾何。

而實測那個漸變段只夠 **27.8 km/h**（見 `docs/timeline-116.md`），
原道路速限 50 要求 3.5°、實測 11.4°。

〔已撤銷 2026-09-21，見 `docs/reproducibility-2026-09-21.md`：同一張照片換編碼即移動 11.5–17.3 度〕此段的論證仍成立，但 11.4° 與 27.8 km/h 兩個數字不再是本專案主張的量測值。

## 「誰畫圖」的答案，分兩層

**捷運本體的設計圖**：中興工程顧問 / 林同棪工程顧問。

**施工期間的標線配置圖**（也就是槽化線那片）：**不是同一批人**。
交通維持計畫通常由**施工廠商或其交通顧問**繪製，**監造審查**，
**地方交通主管機關核定**。

所以那片槽化線的責任鏈是：

```
遠揚營造（或其交維顧問）繪製
  → 林同棪工程顧問 監造審查
    → 新北市交通局 核定
      → 新北市捷運工程局 業主
```

**交維計畫本身還沒拿到**，這一段是依一般程序推論，不是查到的文件。
要確認就得取得那份計畫。
