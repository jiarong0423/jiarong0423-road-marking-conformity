# 偵測器:全部標為隔離,計數一律不可引用

2026-09-22。這不是「程式搬走了」—— `src/marking/` 裡的偵測器仍在,
`assess()` 仍會呼叫它們。**隔離的是它們的「輸出可以被當成證據」這件事。**

## 為什麼

主軸是使用者提出的四個情境。**四點的證據鏈是公文加照片,沒有一點是靠偵測器計數成立的。**
而四個偵測器裡,三個的計數經人眼逐張打開檢查後不成立:

| 偵測器 | 程式報的 | 人眼打開看過之後 |
|---|---|---|
| `_kerbside_red` §169 | 25/42 | 打開 23 個,**13 個不是紅線**(黃水馬 ×4、雙黃線 ×3、素灰混凝土 ×4、一個店面招牌) |
| `_works_hoarding` | 9/42 | 打開 3 個都對,但**框的面積只有 31.8% 是圍籬**,敘事引用的「佔畫面寬度 68%」量的是外接框 |
| `_double_white` §167 | 1/42 | **那一筆是偽陽性**;而真正存在的那條線它漏掉(E47、E52、E54) |
| `_surface_types` | 34/42 | 未定種子時同一張照片會給不同答案(E43);已定種子,但跨種子散布未量(G25) |
| `taper_ensemble` | 5/42 @50 | 判定對速限**平方敏感**,而施工期速限只有目擊證詞加 F07 路面漆的兩處「30」 |
| 水溝蓋 | — | **沒有偵測器。** `_grated_cover` 2026-09-21 移除,無替代 |

## 這代表什麼

**偵測器目前的用途是「指出值得人去看哪裡」,不是「判定那裡有什麼」。**
這句話要寫進產品,不是寫在註腳。

一個 25/42 的紅線計數,如果 13 個是錯的,它作為統計沒有意義 ——
但它作為「這 25 張值得你打開看」是有用的,而且省下打開 42 張的力氣。
